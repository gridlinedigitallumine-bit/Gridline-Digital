Before you run ads

  1. Create a pixel or tag in each ads account (Meta, TikTok, Google).
  2. Open Pixels and ads and paste each ID.
  3. Download tracking-config.js and replace the same file on your website.
  4. Check each platform’s test tool: Meta Events Manager, TikTok Ads, Google Tag Assistant.
  5. Add a privacy policy page to your site, then start your campaigns.

Pixels and ads

Open each platform’s manager, copy its Pixel or tag ID, then paste it here. This connects the website’s tracking to that ad account; it does not sign in to or grant account access to Meta, TikTok, or Google. Pixel IDs are public. Never paste passwords or access tokens.

Many regions require consent before advertising cookies are set. Keep this on unless you have advice that you can turn it off.

Publish changes

  1. Download the file below.
  2. Replace tracking-config.js on your website with it.
  3. Deploy the site. Changes go live after the deploy.
